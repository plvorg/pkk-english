# 已读书籍英文文本库

本目录保存已经阅读过的书籍英文文本，用于后续查阅、管理、词汇统计和句式分析。

## 存放规则

- 每套书籍使用一个 Markdown 文件，直接放在本目录中；独立成册的书也可单独保存为一个文件。
- 文件名使用 `书籍系列名.md`；需要区分级别或版本时使用 `书籍系列名-级别或版本.md`，避免使用 `/`、`\`、`:` 等路径特殊字符。
- 文件以一级标题标明整套书名，按原书顺序用二级标题区分各册，用三级标题区分章节或页码（如有需要）。
- 正文保留英文原文、大小写、标点和段落，不混入中文翻译、练习答案或分析内容，以便后续提取文本。
- 只收录已经阅读过的内容；同一套书后续新增已读册目时，继续追加到原文件。
- 录入时核对原书；无法辨认的文字标记为 `[待核对]`，不自行补写。
- 新增书籍文件后，在下方索引补充链接，方便查找。

## 单套书籍文件模板

将下面模板保存为 `books/书籍系列名.md`，替换占位内容；不需要的可选信息可以删除。

```markdown
# 书籍系列名

- 作者：待填写（可选）
- 出版社 / 版本：待填写（可选）
- 级别：待填写（可选）
- 文本来源：待填写
- 收录范围：已读册目名称或编号

## 01. 第一册英文书名

在这里录入该册英文原文。

## 02. 第二册英文书名

在这里录入该册英文原文。
```

书籍文件建立后，索引链接格式为：`- [书籍系列名](书籍系列名.md)`。
