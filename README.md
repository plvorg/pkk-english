# 小学英语学习工作区

用于英语辅导、学习记录和已读书籍英文文本归档。

## 项目入口

- [辅导工作规则](AGENTS.md)：教学方式、文件维护和输出要求。
- [学生学习档案](learning-profile.md)：学生基本情况、学习特点与辅导记录。
- [英语学习进度](learning-progress.md)：已学习单词及语法/句式清单。
- [已读书籍](books/README.md)：按套保存书籍英文文本，供查阅、管理和分析。
- `prompts/`：各类英语辅导任务的提示词模板。
- `docs/`：练习、阅读材料等文档；生成的 Word 文档按 `YYYY-MM-DD-主题.docx` 命名。
